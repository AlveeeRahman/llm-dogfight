LLM Dogfight

A terminal UFO dogfight between two local LLMs: two small open models, running on your own machine, command rival saucer teams.

Source on GitHub Download binaries Documentation

What you are looking at

Team ZORB and team KRELL are each commanded by a different local model. About once a second every model reads a text description of the field and answers with one order per saucer: attack, hunt, flee, or abduct a cow. Losses make them shout, and every loss becomes a lesson in their prompt. Nothing is fine-tuned; the models stay small (0.6B to 1.7B by default) and the whole thing fits an 8 GB GPU, or Apple silicon through MLX.

The commanders' battle cries and lessons, top of the screen.

Refusal-free ("abliterated") builds have more to say.

Run it

cargo install --git @GITHUB@      # Rust toolchain: https://rustup.rs
pip install torch transformers        # NVIDIA GPU   — or —   pip install mlx-lm   # Apple silicon
dogfight                              # first run downloads the two default models (2.2 GB)
dogfight models                       # the catalogue, and the strongest pair your machine can hold
dogfight evolve                       # let a genetic algorithm evolve each team's tactics

No GPU? dogfight ufo plays with the built-in pilots. A live browser demo would need a GPU Space, which Hugging Face only offers on paid plans, so the game runs on your machine: it is a 0.8 MB binary plus a Python sidecar.
